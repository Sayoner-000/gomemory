# Ediciones anteriores de las guías

Cada release publica una edición de la guía SDD y de la guía técnica con la
versión en el nombre. La edición vigente está en `docs/`; aquí se conservan las
anteriores sin cambios, para consultar cómo funcionaba una versión concreta.

| Archivo | Edición | Versiones documentadas |
|---|---|---|
| `Guia-SDD_GOMEMERY-v2.35.html` | Guía SDD, edición 2 | Spec Kit 0.15.1 · gomemory 2.28.0 (publicada junto a v2.35) |
| `Guia-SDD_GOMEMERY-v2.36.html` | Guía SDD, edición 3 | Spec Kit 1.2.2 · gomemory 2.36.3 |
| `Guia-Tecnica_GOMEMORY-v2.36.html` | Guía técnica, edición 1 | gomemory 2.36.3 |
| `Guia-SDD_GOMEMERY-v2.37.html` | Guía SDD, edición 4 | Spec Kit 1.2.2 · gomemory 2.37.0 |
| `Guia-Tecnica_GOMEMORY-v2.37.html` | Guía técnica, edición 2 | gomemory 2.37.0 |

Vigentes en `docs/`: `Guia-SDD_GOMEMERY-v2.38.html` (edición 5) y
`Guia-Tecnica_GOMEMORY-v2.38.html` (edición 3). El procedimiento está en
[release_gomemory_notes.md](../release_gomemory_notes.md#versionar-las-guías-html).
